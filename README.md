# ویژه‌نامه شماره یک

## «چطور یک چت‌بات هوشمند با اطلاعات شخصی بسازیم؟»

📘 **Cyber SUTECH Journal — Special Issue 1**

این ویژه‌نامه به موضوع **Retrieval-Augmented Generation (RAG)** و ساخت دستیارهای هوشمند مبتنی بر اطلاعات اختصاصی می‌پردازد.

در این شماره، مفاهیم اصلی یک سیستم RAG از آماده‌سازی و **Chunking** اسناد تا **Embedding، Vector Database، Retrieval، Reranking** و تولید پاسخ توسط **LLM** بررسی شده است.

همچنین یک نمونه عملی از پیاده‌سازی RAG با استفاده از ابزارها و کتابخانه‌هایی مانند:

* **LangChain**
* **PyPDFium2**
* **HuggingFace Embeddings**
* **FAISS**
* **OpenAI-compatible APIs**

ارائه شده است.

## 📄 مطالب این شماره

* مبانی و معماری RAG
* روش‌های مختلف Chunking
* Embedding و Vector Database
* Semantic Search و Hybrid Search
* Top-K و Reranking
* Context و Prompt Engineering
* Memory در سیستم‌های مکالمه‌ای
* مقایسه LangChain و LlamaIndex
* پیاده‌سازی یک نمونه RAG
* بررسی خروجی و نتایج پیاده‌سازی
